# Creepster

Die Datei `creepster-latin.woff2` ist eine unveränderte, lokal eingebundene
Google-Fonts-Webfont-Ausgabe von Creepster (Regular, Gewicht 400). Sie wird
zusammen mit der vollständigen Lizenz `OFL-Creepster.txt` ausgeliefert.

- Designer: Sideshow.
- Copyright: 2011 Font Diner, Inc; reservierter Schriftname „Creepster“.
- Lizenz: SIL Open Font License 1.1.
- Offizielle Metadaten: https://raw.githubusercontent.com/google/fonts/main/ofl/creepster/METADATA.pb
- Offizielle Lizenz: https://raw.githubusercontent.com/google/fonts/main/ofl/creepster/OFL.txt
- Upstream: https://github.com/googlefonts/creepster
- Google-Fonts-CSS-Ausgabe: https://fonts.googleapis.com/css2?family=Creepster&display=swap
- Unveränderte WOFF2-Quelldatei: https://fonts.gstatic.com/s/creepster/v13/AlZy_zVUqJz4yMrniH4Rcn35fh4Dog.woff2
- Abrufdatum: 10. Oktober 2026.

Die Schrift wird ausschließlich vom eigenen Website-Host geladen; es gibt
keine Laufzeit-Anfrage an Google Fonts. Die separat gespeicherte Lizenz
ist für die Weiterverteilung beizubehalten.

Der lateinische Zeichensatz enthält die Zeichen der verwendeten Zeile
„Endet vor Halloween — damit ihr feiern könnt.“ einschließlich „ö“ und
Gedankenstrich. Die lokale WOFF2-Datei wurde in Chromium über `FontFace`
geladen. Ein Vergleich aller verwendeten Zeichen mit unterschiedlichen
Fallback-Schriften bestätigte, dass sie aus Creepster dargestellt werden.
